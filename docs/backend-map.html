How a test reaches the network

The local backend has no HTTP API. Each test calls Python objects, and those objects run commands inside the lab containers with docker exec and parse the JSON that comes back. Pick a test on the right and step through it, or click any device on the map to see what the framework can do with it.

Use the backend yourself

The closest thing to an API is the Python object model. Open a shell in the repo (inside the VM) and call it directly. Every call runs a real command in a container and returns parsed data, the same calls the tests make.

uv run python
>>> from pathlib import Path
>>> from netcheck.intent import load_intent
>>> from netcheck.backends import get_backend
>>> lab = get_backend("local", load_intent("intent/lab.yaml"), Path("."))
>>> devs = lab.devices()
>>> devs["r1"].ospf.neighbors()
[OspfNeighbor(router_id='2.2.2.2', state='Full', port='p2'),
 OspfNeighbor(router_id='2.2.2.2', state='Full', port='p3')]
>>> devs["sw1"].bridge.vlan_membership()["p3"]
PortVlans(mode='access', vlans=(20,))
>>> devs["h1"].shell.ping("10.0.30.14", count=3)
PingResult(src='h1', dst='10.0.30.14', sent=3, received=3, ...)
>>> devs["r1"].log.summary()          # every command that ran
["[r1] exec: vtysh -c 'show ip ospf neighbor json' rc=0 (0.05s)", ...]

Copy gives you the commands without the >>> prompts; paste them after starting uv run python. Outputs above show the shape of what comes back on a healthy lab; your values will match your lab. Calls that change state (links.set_link, bridge.set_access_vlan) are real: finish with make lab-reset.

See the live lab

Containerlab can draw the running topology in a browser. In the VM:

sudo containerlab graph -t build/campus-mini/campus-mini.clab.yml

It serves the graph on port 50080. With OrbStack, open http://netlab.orb.local:50080 on your Mac.

Look at what a test looked at

  1. build/campus-mini/expected_state.json: what tests assert against
  2. .netcheck/snapshots/<id>.json: the state saved before each test
  3. artifacts/<test>/logs/<device>.jsonl: every command a failed test ran, with the raw reply
  4. artifacts/<test>/*.pcap: open in Wireshark

The NVIDIA backend

On Cumulus, the same capabilities would call the NVUE REST API (port 8765) instead of docker exec. Tests and assertions stay the same; only the bottom two layers change. That backend is not finished yet.
