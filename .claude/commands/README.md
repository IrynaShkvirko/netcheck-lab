# Commands

Slash commands for netcheck's workflow. Git conventions live in
`.claude/skills/git-workflow/SKILL.md`; the agents and the full workflow in
`.claude/agents/README.md`.

| Command | Does |
| --- | --- |
| [/brainstorm](brainstorm.md) | idea -> agreed design document |
| [/plan](plan.md) | requirements or design -> implementation plan |
| [/create-branch](create-branch.md) | branch off the latest `master` |
| [/commit](commit.md) | commit the staged change in the repo's style, after `make check` |
| [/create-pr](create-pr.md) | push and open a PR with Summary, Evidence, Merge Danger |
