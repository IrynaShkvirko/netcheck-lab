# Skills

Project skills, loaded on demand or through an agent's `skills:` frontmatter. Plugin skills
(`mattpocock-skills:*`: tdd, diagnosing-bugs, codebase-design, domain-modeling, pr, ...) are
installed separately and complement these.

| Skill | Scope | Use when |
| --- | --- | --- |
| [netcheck-backend](netcheck-backend/SKILL.md) | code | writing or reviewing backends, transports, parsers, lifecycle, snapshots, timing |
| [netcheck-testing](netcheck-testing/SKILL.md) | tests | writing unit tests over fakes or lab tests with steps |
| [network-security](network-security/SKILL.md) | code, CI | credentials, connections, commands, logs, CI, dependencies |
| [mutation-testing](mutation-testing/SKILL.md) | tests | checking that tests would catch a bug (mutmut) |
| [brainstorming](brainstorming/SKILL.md) | process | shaping an idea into a design |
| [writing-plans](writing-plans/SKILL.md) | process | turning requirements into an implementation plan |
| [safe-refactoring](safe-refactoring/SKILL.md) | process | restructuring without changing behaviour |
| [systematic-debugging](systematic-debugging/SKILL.md) | process | a failing test, a misbehaving lab, a fix that did not work |
| [git-workflow](git-workflow/SKILL.md) | process | branches, commits, PRs |
